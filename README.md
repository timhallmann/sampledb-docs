# SampleDB Documentation

This repository contains the [Sphinx](https://www.sphinx-doc.org/)-based documentation, including generated images, for prior versions of [SampleDB](https://github.com/sciapp/sampledb). It is used to build the versioned [SampleDB documentation](https://scientific-it-systems.iffgit.fz-juelich.de/SampleDB/).

**Note:** The current documentation is maintained in the [SampleDB repository](https://github.com/sciapp/sampledb). If you encounter any issues with the SampleDB documentation or want to contribute, please do so there, unless the issue you are trying to address is specific to *this* repository.
